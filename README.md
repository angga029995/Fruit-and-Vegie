# 🍎🥦 Fruit and Vegie

Aplikasi katalog produk buah dan sayuran dengan antarmuka modern dan responsif.

## 🌐 Website Publik

[🔗 Buka FreshCatalog](https://angga029995.github.io/Fruit-and-Vegie/)

Repositori dan website ini dapat diakses publik. Katalog terbuka langsung tanpa perlu masuk atau melewati layar intro.

## ✨ Fitur Utama

- **Katalog Lengkap**: Daftar produk buah dan sayuran
- **Pencarian Cepat**: Cari berdasarkan nama, SKU, atau barcode
- **Pengurutan Fleksibel**: Urutkan A→Z, Z→A, SKU, Barcode, atau terbaru
- **Tambah dan Kelola Produk**: Tambahkan produk, lalu kelola atau hapus produk tambahan
- **Export CSV**: Unduh data katalog dalam format CSV
- **Responsive Design**: Optimal di perangkat mobile, tablet, dan desktop

## 📱 Cara Penggunaan

1. Buka link website publik di atas.
2. Cari produk berdasarkan nama, SKU, atau barcode.
3. Gunakan tombol pengurutan untuk menyesuaikan tampilan.
4. Klik tombol `+` untuk menambahkan produk baru, atau pilih **Kelola** untuk menghapus produk tambahan.
5. Gunakan tombol **Export** untuk mengunduh data.

> **Penyimpanan produk tambahan:** Website ini merupakan aplikasi statis tanpa server atau akun. Produk tambahan tersimpan di penyimpanan lokal browser/perangkat yang membuatnya; produk tersebut tidak dibagikan atau disinkronkan ke perangkat pengunjung lain. Untuk penyimpanan bersama lintas perangkat, diperlukan backend/database dan pengaturan akses tersendiri.

## 📊 Struktur Data

- **Barcode**: Kode barcode produk
- **SKU**: Stock Keeping Unit
- **Description**: Nama dan deskripsi produk

## 🛠 Teknologi

- **HTML5**: Struktur markup
- **CSS3**: Styling responsif dan animasi
- **Vanilla JavaScript**: Interaktivitas tanpa framework
- **GitHub Pages**: Hosting website statis
